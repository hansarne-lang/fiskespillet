# Første fiskeøkt

Start vert og klient som beskrevet i [LAN_DAY.md](LAN_DAY.md). Gå om bord med E i begge vinduer, og start [båtturen](BOAT_TRIP.md) med R som kaptein etter 02:00.

Ved fiskeplassen får hver spiller om bord én stang. Trykk F i hvert vindu. Begge skal vise «Stang 1: Fisker», også når én av spillerne trykker F flere ganger. Serveren beregner første napp uavhengig for hver stang. Klokken 17:00 avsluttes fiskingen.

Denne prøven viser stangen i HUD-en. Fiskekamp, fangst og 3D-stang følger separat.
