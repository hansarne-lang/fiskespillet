# Enkel 3D-visning

Start vert og lokal klient som i FULL_DAY.md. Visningen bruker motorens primitive former, materialer og lys. Startbåten har skrog, dekk, konsoll, motor og to stenger. Kameraet følger båten fra siden og bakfra. Ved retur snur båten og kameraet hjemover. Ved brygga vises den grønne marinasonen.

Stengene beveger seg i bølgene, bøyes under kamp og viser line når de fisker. Serveren deler bare de fysiske aktivitetene hvile, fiske og kamp. Fangstdata, vekt, salgsverdi og saldo følger den eksisterende oppgjørsbarrieren ved 17:00.

Bruk E for å gå om bord, R som kaptein for å reise, F for å sette ut og museknappene og mellomrom for kamp og landing. Hav, båtmodell og animasjoner er enkle prototypemodeller. Ingen nye binære ressurser legges i repositoryet.

Test med to lokale prosesser og -FiskLanSmoke. Visuell kontroll skal dekke brygga, reise, fiske, kamp og hjemreise. Claude-gjennomgangen venter til lørdag.
