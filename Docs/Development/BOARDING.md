# Ombordstigning i LAN-prototypen

Start vert og klient som beskrevet i [LAN_DAY.md](LAN_DAY.md). Begge starter ved brygga og trykker E hver for seg. Startbåtens besetning endres fra 0/2 til 1/2 og 2/2. Gjentatt E endrer ikke antallet. Hvis klienten kobler fra, skal verten se at plassen frigjøres.

Verten eier startbåten og er kaptein når verten er om bord. Hvis bare gjesten er om bord, er gjesten midlertidig kaptein. Ombordstigning vises i HUD-en. Båtmodell og bevegelse kommer i senere oppgaver.
